# 消えた写真・動画の復元ツール（無料）

SD カード、USB メモリ、外付けドライブ、パソコンのドライブから**削除してしまった写真・動画**を取り戻すためのプログラムです。

ファイルを削除しても、データそのものはドライブの空き領域に残っています（新しいデータで上書きされるまで）。このツールはドライブを先頭から最後まで直接読み、残っている写真・動画のデータを探し出して、**撮影した年・月ごとのフォルダ**に書き出します。

- 元のドライブには一切書き込みません（読み取り専用）
- インターネットには接続しません。データはどこにも送信されません
- Python（無料）以外に必要なものはありません

## アプリをダウンロード（おすすめ）

Python を入れなくても、ダブルクリックで使えるアプリです。

**[最新版のダウンロードページ](../../releases/tag/app-latest)** の「Assets」から、パソコンに合うものを選んでください。

| パソコン | ファイル |
|---|---|
| Windows 10 / 11（おすすめ） | `Fukugen-Windows.zip`（展開して中の `Fukugen.exe` を開く） |
| Windows 10 / 11（1 ファイル版） | `Fukugen-Windows.exe` |
| Mac（M1〜M4 などの Apple シリコン） | `Fukugen-Mac-AppleSilicon.zip` |
| Mac（Intel） | `Fukugen-Mac-Intel.zip` |

### アプリの使い方

1. アプリを開きます。
   - **Windows**：「このアプリがデバイスに変更を加えることを許可しますか？」で「はい」。「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
   - **Mac**：zip を開いて出てきた「Fukugen」を「アプリケーション」に入れて開きます。「開発元を確認できない」と出たら、「システム設定」→「プライバシーとセキュリティ」の下にある「このまま開く」を押します。ドライブを選ぶと管理者のパスワードを聞かれます。
2. 復元したいドライブを選んで「スキャンを始める」を押します。
3. 見つかった写真・動画が、撮影した**年・月ごと**に一覧になります（サムネイル付き）。選ぶと右に大きく表示され、動画は「アプリで開いて見る」で中身を確かめられます。
4. 取り戻したいものにチェックを付けて「チェックしたファイルを復元する」を押し、**別のドライブ**の保存先を選びます。

アプリは署名されていないため、初回だけ上の確認が出ます。

### 「安全ではない」と出てブロックされたとき

このアプリには有料の電子署名が付いておらず、使った人もまだ少ないため、Windows やブラウザが念のため止めます。中身が危険と判定されたわけではありません（プログラムの中身はすべてこのページで公開しています）。止められた場所ごとに、次のように進めます。

**ダウンロードの時点で止められた（ブラウザ）**
- **Edge**：「一般的にダウンロードされていません」の横の「…」→「保存」→「詳細表示」→「保持する」
- **Chrome**：ダウンロードの一覧で「安全でない可能性があります」の横の「︙」→「安全でないファイルを保存」

**開こうとしたら止められた（Windows）**
- 「Windows によって PC が保護されました」→「詳細情報」→「実行」
- それでも開けないときは、ダウンロードしたファイル（zip 版なら展開する前の zip）を右クリック →「プロパティ」→ いちばん下の「許可する」にチェック →「OK」。そのあと展開して開きます。

**ファイルが消えた・「ウイルスが検出されました」と出た（Windows セキュリティ）**
- 「Windows セキュリティ」→「ウイルスと脅威の防止」→「保護の履歴」→ Fukugen の項目 →「操作」→「許可」または「復元」

**警告が出ない方法（Python から起動する）**
exe を使わず、Python（公式の署名付きソフト）から同じアプリを起動する方法です。

1. [python.org](https://www.python.org/downloads/) から Python を入れます（無料）。インストール画面で「Add python.exe to PATH」にチェック。
2. このページの緑の「Code」→「Download ZIP」でダウンロードして展開します。
3. Windows は `start_app_windows.bat`、Mac は `start_app_mac.command` をダブルクリックします（初回だけ、画像表示の部品を自動で入れます）。

画面と使い方は exe 版とまったく同じです。

## 取り戻せるもの

| 種類 | 形式 |
|---|---|
| 写真・画像 | JPEG、HEIC（iPhone）、PNG、GIF |
| 動画 | MP4、MOV |

撮影日時（写真の EXIF、動画の作成日時）を読み取り、`2019年/08月/2019-08-03_142210_….jpg` のように保存します。日時が残っていないものは `日付不明` フォルダに入ります。終わると `復元結果を見る.html` が作られ、ブラウザで年代別に一覧できます。

## Python で動かす場合（上級者向け）

### 始める前に（大事）

1. **消したドライブを使うのをやめてください。** 写真を撮る、ファイルを保存するなど、書き込むほど上書きされて戻せなくなります。
2. **保存先は別のドライブにしてください。** SD カードから復元するなら、パソコン本体に保存します。同じドライブを選ぶと、ツールが止めます。

### Windows

1. [python.org](https://www.python.org/downloads/) から Python をダウンロードして入れます（無料）。インストール画面の **「Add python.exe to PATH」にチェック**を付けてください。
2. このページの緑の「Code」ボタン →「Download ZIP」でダウンロードし、展開します。
3. `start_windows.bat` をダブルクリックします。
4. 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押します（ドライブを直接読むために管理者の権限が必要です）。
5. 一覧からドライブの番号を選び、保存先を決めて始めます。

SD カードがドライブ文字（E: など）で出てこない場合や「フォーマットしますか」と聞かれる場合は、一覧の「ディスク ○ 全体」を選んでください。

### Mac

1. ZIP をダウンロードして展開します。
2. `start_mac.command` をダブルクリックします（開けないときは、右クリック →「開く」）。
3. 管理者のパスワードを入力します（入力中は文字が表示されません）。
4. 一覧から番号を選びます。外付けやカードは `disk4` のような名前で出てきます。

「アクセスが拒否されました」と出たら、「システム設定」→「プライバシーとセキュリティ」→「フルディスクアクセス」で「ターミナル」を許可してから、もう一度開いてください。

### Linux

```
sudo python3 fukugen.py
```

### イメージファイルから復元する

ほかのソフトで作ったドライブのイメージ（`.img` / `.dd` / `.bin`）も読めます。一覧の最後の番号を選ぶか、次のように指定します（管理者権限は不要です）。

```
python3 fukugen.py card.img 保存先フォルダ
```

## オプション

| オプション | 内容 |
|---|---|
| `--keep-small` | アイコンなど小さい画像（256 px 未満）も保存する |
| `--all-offsets` | ファイルの区切り以外の位置も探す。遅くなるが、ほかのファイルに埋め込まれた画像も見つかる |
| `-y` | 確認せずに始める |

## 取り戻せないもの

- **上書きされたデータ。** 削除後にたくさん書き込んだドライブでは、見つからないことがあります。途中まで上書きされた写真は、残っている部分だけ取り出し、ファイル名に「一部欠損」と付けます。
- **SSD から削除したデータ。** SSD は削除後すぐに中身を消去する（TRIM）ことが多く、見つからない場合があります。
- **スマホ本体（内蔵ストレージ）。** 中身が暗号化されているため、このツールでもほかのソフトでも読み出せません。
- **ばらばらの場所に記録されていたファイル。** 断片化したファイルは途中から別のデータが混ざることがあります（SD カードの写真はほとんどの場合、連続して記録されています）。
- **索引（moov）が無い動画。** 録画中の電源断などで壊れた動画は「索引が無い動画」フォルダに入れます。同じ機種で撮った正常な動画があれば、ファイル修復ラボのページで作り直せます。
